# Oscilloscope-500kHz
A beginner-friendly project focused on learning STM32-based embedded systems, PCB design, and analog signal acquisition. The goal of this project is to gain hands-on experience in designing a complete oscilloscope, from the analog front end to firmware and hardware integration.

The oscilloscope is designed with a target bandwidth of 0–500 kHz, an input range of 0–23 V, and 12-bit resolution. These specifications were chosen to create a low-cost instrument capable of troubleshooting analog audio circuits and other low-frequency electronic systems, without the cost and complexity of a conventional 200 MHz-class oscilloscope.

While not intended to compete with professional test equipment, this project serves as a practical platform for exploring embedded systems, mixed-signal circuit design, and PCB development.
